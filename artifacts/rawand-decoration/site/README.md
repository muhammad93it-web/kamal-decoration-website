# دیکۆراتی ڕەوەند — Rawand Decoration

ماڵپەڕی فەرمی **دیکۆراتی ڕەوەند** — ڕانیە، کوردستان. 📞 0750 103 8181

- زمان: کوردی سۆرانی (RTL)
- تەکنەلۆژیا: PHP 8.1+ · MySQL · HTML/CSS/JS (بێ فرەیمۆرک)
- شوێنی کارکردن: هۆستینگی هاوبەش (Namecheap cPanel) یان هەر سێرڤەرێکی Apache+PHP+MySQL

---

## ١) دامەزراندن لەسەر Namecheap (cPanel)

### ئامادەکاری
1. لە cPanel بچۆ بۆ **MySQL® Databases**:
   - بنکەدراوەیەک دروست بکە (نموونە: `user_rawand`)
   - بەکارهێنەرێکی بنکەدراوە دروست بکە و وشەی نهێنییەکی بەهێز دابنێ
   - بەکارهێنەرەکە زیاد بکە بۆ بنکەدراوەکە و **ALL PRIVILEGES** هەڵبژێرە
2. لە cPanel بچۆ بۆ **Select PHP Version** و دڵنیابە لە:
   - PHP **8.1** یان نوێتر
   - ئێکستێنشنەکان: `pdo_mysql` ، `mbstring` ، `gd` ، `fileinfo` (زۆربەی کات خۆیان چالاکن)

### بارکردنی فایلەکان
3. هەموو ناوەڕۆکی ئەم فۆڵدەرە (فایلەکانی ناو `site/`) زیپ بکە و لە **File Manager** باری بکە بۆ ناو `public_html` پاشان Extract بکە.
   - دڵنیابە فایلی `.htaccess` هەیە (فایلە شاراوەکان پیشان بدە: Settings → Show Hidden Files)

### دامەزراندن
4. لە وێبگەڕ بکەوە: `https://domain-eket.com/install`
5. هەنگاوەکان جێبەجێ بکە:
   - **هەنگاوی ١:** پشکنینی سێرڤەر — هەموو ✓ بن
   - **هەنگاوی ٢:** زانیاری بنکەدراوە بنووسە (هۆست: `localhost`)
   - **هەنگاوی ٣:** هەژماری بەڕێوەبەر دروست بکە
6. دوای تەواوبوون:
   - بچۆ بۆ `/admin` و بچۆ ژوورەوە
   - لە **ڕێکخستنەکان ← لۆگۆ و ناسنامە** لۆگۆکەت داببنێ (وێنەکە هەروەک خۆی هەڵدەگیرێت)
   - لە **ئامرازەکانی QR** دوگمەی «نوێکردنەوەی هەموو QR و بارکۆدەکان» دابگرە
   - بۆ پاراستن فۆڵدەری `install` بسڕەوە

| بەش | کار |

## ٣) گواستنەوە بۆ دۆمەینی نوێ

1. فایلەکان و بنکەدراوەکە بگوازەوە (باکئەپی SQL لە **باکئەپ** دابگرە و لە phpMyAdmin بارِی بکە)
2. `config/config.php` نوێ بکەوە بە زانیاری بنکەدراوەی نوێ
3. لە **ئامرازەکانی QR**: لینکی نوێ بنووسە و «نوێکردنەوەی هەموو» دابگرە — هەموو QRەکان بە دۆمەینی نوێ دروستدەبنەوە

## ٤) باکئەپ

- **داتا:** ئەدمین ← باکئەپ ← داگرتنی فایلی SQL
- **وێنەکان:** فۆڵدەری `uploads/` لە File Manager کۆپی بکە
- باشترە هەفتانە باکئەپ بگریت

## ٥) چارەسەری کێشە

| کێشە | چارەسەر |
|---|---|
| هەڵەی 500 | دڵنیابە `.htaccess` بارکراوە؛ مۆڵەتی فۆڵدەرەکان 755 و فایلەکان 644 بن |
| وێنە بارناکرێت | مۆڵەتی `uploads/` با 755 بێت؛ قەبارەی وێنە کەمتر لە 15MB |
| QR دروستنابێت | دڵنیابە فۆڵدەری `libraries/vendor/` بارکراوە (لەگەڵ پڕۆژەکە دێت) |
| PDF کار ناکات | فۆنتەکانی `assets/fonts/pdf/` پێویستن؛ ئەگەر نەبوو دوگمەی چاپکردن بەکاربهێنە |
| ماڵپەڕ داخراوە | لە ڕێکخستنەکان «دۆخی چاککردنەوە» بکوژێنەوە |

## تێبینی تەکنیکی (بۆ گەشەپێدەر)

- `database.sql` — خشتەکان + داتای نموونەیی کوردی
- `config/config.example.php` — نموونەی ڕێکخستن
- `includes/` — ناوکی سیستەم (bootstrap, auth, csrf, codes, uploads…)
- `admin/` — بەشی بەڕێوەبردن
- `libraries/vendor/` — کتێبخانە باروکراوەکان (mPDF, QR, barcode, HTMLPurifier) — پێویستی بە ئینتەرنێت نییە
- هەموو JS و فۆنتەکان لۆکاڵن — هیچ CDNێک بەکارنەهاتووە
